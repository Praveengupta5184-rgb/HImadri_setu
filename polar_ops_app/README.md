# POLAR-OPS Flutter App

## Setup:
1. Install Flutter SDK
2. Run: `flutter pub get`
3. Run: `flutter run`

## Features:
- QR Scanner
- OCR
- Voice SOS
- Offline Support (Hive)
- Reports (PDF/Excel)
